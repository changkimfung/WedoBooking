# W.BOL 说明与 FAQ

> <span style="color:#1677ff">2026-06-05 新增文档</span>

> W.BOL（WEDO Bill of Lading）为预约送仓流程中的**入仓凭证**，凭证正文为全英文，面向海外仓收货口。  
> 模板路径：散货 `/fg/w.Pod散货模板.html`；整柜 `/fg/w.pod整柜模板.html`；渲染脚本 `fg/js/wpod-render.js`。

---

## 1. 下载节点

| 预约状态 | 可否下载 |
| --- | --- |
| 待提交 / 待预约 / <span style="color:#1677ff">仓库待审核</span> / 客户待确认 | ✗ |
| **待送仓** | **✓** |
| **已送仓** | **✓** |
| 预约失败 / 已废弃 | ✗ |

**规则：** 货代/客户**确认接受仓库时段**后（状态 → 待送仓），系统才开放 W.BOL 下载。

**入口：**

| 入口 | 说明 |
| --- | --- |
| 货代端详情 | 字段「W.BOL 下载」→ 点击链接 |
| 海外仓详情 | 待送仓 / 已送仓 展示下载链接 |
| 直链 | 散货：`/fg/w.Pod散货模板.html?code={送仓码}`；整柜：`/fg/w.pod整柜模板.html?code={送仓码}` |

系统按预约「送仓类型」自动选择 LCL / FCL 模板，无需手动切换。

**打印：** 打开模板页 → `Print / Save as PDF`，交由司机随货携带。

## 2. 字段说明

### 2.1 公共字段（LCL / FCL）

| 字段 | 含义 |
| --- | --- |
| Booking Code | 送仓码；条形码内容；到仓扫码主键 |
| Appt. No. | 系统预约单号 |
| Warehouse | 仓库代码（如 CA-91761），非中文仓名 |
| Booked By | 预约方（客户编号；船务渠道为 Wedo Shipping） |
| Type | LCL 散货 / FCL 整柜 |
| Scheduled Delivery Time | 仓库核定的入仓时段 |
| Palletized* | 是否打托（Yes / No） |
| Warehouse Address | 仓库确认收货地址（优先英文） |
| Warehouse Contact | 固定 `-`（暂未接入各仓对外电话） |
| Driver / Consignee Signatory | 司机 / 收货方签字区 |

### 2.2 散货（LCL）额外

| 字段 | 含义 |
| --- | --- |
| Total Cartons | 送仓总箱数 |
| Total Pallets | 送仓总托数；**未打托时留空** |
| Order No. | 入库单号 |
| Shipping Method | 运输方式（英文展示） |
| Order Date | 订单日期（仅日期，无时分秒） |
| Cartons | 该单箱数 |

### 2.3 整柜（FCL）额外

| 字段 | 含义 |
| --- | --- |
| Container No. | 柜号 |
| Container Type | 柜型 |

**页脚提示（摘要）：**

- 散货：到仓须出示本 bill of lading，否则可能被拒收。
- 整柜：须提前 3–5 个工作日预约；**不得提前破封**，否则可能拒收。

## 3. 常见 FAQ

| # | 问题 | 回答 |
| --- | --- | --- |
| Q1 | 为什么「客户待确认」还不能下载？ | 时段尚未最终确认；货代接受后才变为「待送仓」并开放下载。 |
| Q2 | 散货 / 整柜怎么选模板？ | 系统按「送仓类型」自动路由，无需手动选择。 |
| Q3 | Booking Code 和 Appt. No. 区别？ | Booking Code = 送仓码（扫码用）；Appt. No. = 系统单号（对账用）。 |
| Q4 | Total Pallets 为什么是空的？ | 未打托时不展示托数，属正常。 |
| Q5 | 已送仓还能下载吗？ | 可以；「待送仓」「已送仓」均保留下载入口。 |
| Q6 | 撤回 / 重新预约后旧 BOL 还有效吗？ | 无效；协商字段清空，需重新审核确认后生成新凭证。 |
| Q7 | 司机没带 W.BOL 会怎样？ | 可能被拒收或延迟登记；建议「待送仓」后立即打印给司机。 |
| Q8 | 和海运提单是一回事吗？ | 不是。W.BOL 是**入仓预约凭证**；海运 B/L 是头程运输单据。 |
| Q9 | 打开链接提示找不到预约？ | 检查送仓码是否正确、URL 是否带 `?code=` 参数。 |
| Q10 | PDA 扫码和 BOL 条形码是同一个吗？ | 是，均为 Booking Code（送仓码）。 |
