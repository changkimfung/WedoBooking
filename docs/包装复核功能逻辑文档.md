# 包装复核（发货复核）业务逻辑说明

> 适用场景：海外仓出库发货前的包装复核作业
> 涉及角色：仓库复核员（PDA 手持端操作）、仓库管理/跟单人员（电脑端管理）
> 业务目标：在包裹发出前，逐件核对订单商品与实物是否一致，确保"发对的货、发够数量"，并对每一单的复核过程留痕可追溯。

---

## 一、业务背景与目标

海外仓每天有大量订单出库发货。为避免发错货、漏发、多发，每个出库单在发货前需要经过一次**包装复核**：复核员逐件扫描订单商品，系统实时比对“应发”与“实扫”，并完整保留每一轮作业记录。

本功能要解决的核心问题：

1. **防错**：错扫、多扫时即时预警，提交时统一识别少扫、多扫、错扫。
2. **留痕**：记录每轮复核的操作人、时间、扫描明细、异常类型和完结方式，方便追溯。
3. **管控**：管理人员可按发货时间范围查看复核进度、状态分布和完成率。
4. **闭环**：异常订单可重新复核；未完成订单可人工完结；已完成订单禁止重复复核。

---

## 二、整体作业流程

1. 仓库复核员在 PDA 扫描包裹面单号，系统匹配对应出库单。
2. 复核员逐件扫描 SKU，系统实时展示已扫数量与应扫数量。
3. 复核员提交本轮作业，系统生成复核完成或复核异常档案；中途退出则保留部分复核档案。
4. 管理人员在电脑端按发货时间范围查看看板、处理订单、查看档案明细并导出报表。

一个订单可以有多轮复核。每轮均独立留痕，订单最终状态由全部档案综合确定。

---

## 三、PDA 复核操作（仓库复核员）

### 3.1 扫描包裹面单号

- 系统根据面单号找到对应的出库单，并展示该单 SKU 清单。
- 订单状态为**已达标**或**已合规**时，PDA 拦截再次进入，避免重复复核。
- 正在复核 A 单时扫描 B 单，系统会先将 A 单保存为部分复核，再进入 B 单，确保扫描记录不丢失。

### 3.2 扫描商品

- 首次扫描 SKU 后，系统建立本轮复核档案；扫描页面实时显示每个 SKU 的已扫数量和应扫数量。
- 所有扫描均保留记录，包括异常扫描，便于后续核查。
- 扫到不属于当前订单的料号，提示：**该料号不属于当前订单，请检查！**
- 同一 SKU 扫描数量超过订单发货数量，提示：**该料号扫描次数已超过订单发货数量，请检查！**，并展示“料号 已扫 X / 应扫 Y”。

### 3.3 提交与中断

| 本轮结果 | 判定条件 | 后续处理 |
|---|---|---|
| **复核完成** | 每个订单 SKU 的实扫数量与应扫数量一致，且无错扫 | 本轮完成，返回扫描下一单 |
| **复核异常** | 主动提交时存在少扫、多扫或错扫 | 展示问题商品，作业人员可整改后重新复核 |
| **部分复核** | 未主动提交即刷新、关闭、重置或切换订单 | 保留已扫描内容和中断记录 |

---

## 四、复核结果状态说明

### 4.1 单轮复核的结果

| 结果 | 含义 |
|---|---|
| 复核中 | 复核员正在作业，尚未提交 |
| 复核完成 | 已提交，且商品种类、数量与订单完全一致 |
| 复核异常 | 已提交，但存在少扫 / 多扫 / 错扫 |
| 部分复核 | 未提交就中断了，只保留已扫的部分记录 |

### 4.2 订单的整体复核状态

一个订单可有多轮复核，订单层面使用以下五种状态：

| 状态 | 判定规则 | 业务含义 |
|---|---|---|
| **已合规** | 复核次数大于 1 且存在复核完成档案，或存在人工完结档案 | 已完成多轮复核，或经管理人员确认完结 |
| **已达标** | 复核次数为 1 且存在复核完成档案 | 首次复核即完成 |
| **复核异常** | 存在主动提交的复核异常档案，且无复核完成档案 | 已提交但发现少扫、多扫或错扫，需要处理 |
| **部分复核** | 已有档案，但未满足上述状态 | 作业未完成提交或中途停止 |
| **未复核** | 没有任何复核档案 | 尚未开始复核 |

状态标签支持移入或键盘聚焦查看上述说明。已达标与已合规订单不能再次通过 PDA 发起复核。

---

## 五、电脑端管理（管理 / 跟单人员）

### 5.1 发货复核看板

看板按当前选择的**发货时间范围**统计；未填写范围时展示全部发货时间数据。指标包括总发货订单量、已达标订单量、已合规订单量、未复核订单量、部分复核订单量、复核异常订单量和复核完成率。

复核完成率计算方式为：**（已达标订单量 + 已合规订单量）÷ 总发货订单量**。每项指标标题旁均有问号图标，移入或聚焦可查看统计口径。

### 5.2 订单列表与详情

- 可按出库单号、面单号、复核状态及发货时间段查询；列表每页展示 10 条。
- 支持中国时间和美国时间切换，页面展示、按天筛选、看板及导出均以所选时区换算；美国时间自动处理夏令时。
- 点击订单进入独立详情页，查看订单信息、SKU 清单和所有复核档案；打开任一档案可追溯 SKU 扫描明细及逐条扫描日志。
- 有权限的人员可修正档案状态和完结类型，数据会同步影响订单状态和看板。

### 5.3 人工完结

未复核、复核异常和部分复核订单可在列表执行“完结”。系统会新增一条“复核完成 / 人工完结”档案，订单状态变为**已合规**；已达标或已合规订单不展示完结入口。

### 5.4 报表导出

按发货时间范围导出 Excel，包含两个工作表：

| 工作表 | 内容 | 用途 |
|---|---|---|
| 订单列表 | 出库单、复核状态、复核次数、发货时间、复核完成时间、异常分析 | 整体核对、归档与异常归因 |
| 复核日志 | 出库单、复核编号、复核状态、操作人、料号、扫描时间、异常类型 | 逐件追溯与稽核 |

订单列表中的“异常分析”口径如下：已达标和未复核留空；已合规展示“复核次数大于1，值为 X”；部分复核汇总所有非主动提交档案的少扫、错扫、多扫；复核异常汇总主动提交档案的少扫、错扫、多扫。

---

## 六、时间口径约定

- 系统内部统一按**中国时间**保存作业时间。
- 页面展示、查询、看板和导出可切换为**美国时间**（美国太平洋时间，自动处理夏令时）。
- 发货时间筛选和看板统计均以所选时区下的发货日期为准。

---

## 七、关键业务规则一览

| 场景 | 系统处理 |
|---|---|
| 商品全部扫齐，数量与订单一致，且无错扫 | 本轮复核完成 |
| 主动提交时存在少扫、多扫或错扫 | 本轮复核异常，保留异常明细并提示整改 |
| 中途退出、重置或切换订单 | 保存为部分复核，已扫记录不丢失 |
| 扫到别的订单的商品 | 弹窗预警，记录为错扫，订单数量记为 0 |
| 同一商品扫描超出应发数量 | 弹窗预警，记录为多扫，并展示已扫/应扫数量 |
| 单次复核完成 | 订单状态为已达标 |
| 多次复核后完成或人工完结 | 订单状态为已合规 |
| 已达标或已合规订单 | PDA 拦截重复复核 |
| 现场确认无需继续复核 | 管理人员可人工完结为已合规 |

---

## 八、角色与使用入口

| 角色 | 使用端 | 主要操作 |
|---|---|---|
| 仓库复核员 | PDA 手持端 | 扫面单 → 扫商品 → 提交复核 |
| 仓库主管 / 跟单 | 电脑端 | 看看板、查异常、看明细、人工修正、导出报表 |
