预约送仓系统 — 产品定位及功能介绍

面向海外仓 B2B 客户的自助预约送仓平台，解决传统线下 Excel 预约、电话沟通效率低的问题。 客户通过预约码即可在线完成送仓时间选择、货物信息填报及状态跟踪，仓库端同步接收预约并进行排期管理。

一、需求背景

1.1 业务痛点

在项目实施前，客户预约送仓完全依赖线下流程：销售/客服通过微信或邮件收集信息，仓库手工录入 WMS， 信息传递链路长、易出错，且无法实时查看预约状态。高峰期（如黑五前）预约冲突率高达 23%。

核心目标：将预约送仓从「人工协调」升级为「客户自助 + 系统排期」，目标是将预约冲突率降至 5% 以下。

1.2 干系人分析

角色核心诉求系统触点
客户（货主）快速预约、修改/取消、状态可查客户端 Web 页面
仓库操作员预约列表、到仓确认、异常处理仓库端管理后台
销售/客服代客预约、纠纷处理ERP 内嵌模块
船务/调度送仓与头程到港时间联动ASN 预报关联

二、核心功能设计

2.1 三步预约流程

参考分步引导模式，设计了清晰的三步流程：

  1. 输入预约码 — 客户凭销售提供的唯一预约码进入系统
  2. 填写送仓信息 — 选择仓库、预约日期/时段、填写 SKU 及箱数
  3. 确认提交 — 系统校验库容后生成预约单，发送确认邮件

入库管理模块 — 从预报到上架的全链路设计

负责海外仓入库全流程产品设计，涵盖 ASN 预报、收货扫描、质检、上架分配等环节， 打通客户预报数据与仓库实操系统之间的信息壁垒。

一、业务流程

入库流程涉及多角色协作，核心状态流转如下：

状态触发条件操作角色
已预报客户提交 ASN客户 / 销售
已到仓PDA 扫描确认收货仓库操作员
质检中存在待检 SKU质检员
已上架库位分配完成系统自动

二、难点与解法

2.1 预报与实际差异处理

实际收货数量与 ASN 预报不一致是最高频异常（占比约 35%）。 设计了「差异确认」子流程：操作员标记差异 → 系统自动通知客户 → 客户确认处理方式（接受/退回/补发）。

项目作品集/ 供应链系统/ 装柜管理

装柜管理系统 — 头程拼柜与计费一体化

针对头程海运拼柜业务，设计装柜计划、货物装载、费用分摊的完整产品方案， 解决多客户混装场景下的计费争议问题。

一、计费逻辑

装柜费用按体积分摊至各客户订单，核心公式：

客户分摊费用 = 总装柜费用 × (该客户货物体积 / 柜内总体积)

附加费（如超重费、查验费）按约定规则单独计算，并在对账单中分项展示。

项目作品集/ 移动端 / PDA 收货

PDA 收货扫描 — 仓库现场 UX 设计

为仓库一线操作员设计 PDA 端收货扫描应用，针对手套操作、弱网环境、高频扫描等场景进行专项 UX 优化。

一、现场 UX 设计原则

  • 按钮最小点击区域 48×48px，适配手套操作
  • 关键操作（确认收货）需二次确认，防误触
  • 离线模式：断网时本地缓存，恢复后自动同步
  • 扫描反馈：成功/失败用不同颜色 + 震动反馈
